# Third-party notices

Usage has no third-party code. It has no Swift Package Manager dependencies
(`Package.swift` declares none and there is no `Package.resolved`), bundles no
library, font, or model, and ships only the code in this repository.

## House design system

These files are part of the House design system, the shared look of the House
family of Mac apps. They are the author's own work, copied into this
repository so it builds on its own, and are covered by this repository's MIT
license (`LICENSE`, Copyright (c) 2026 Tristan McInnis).

| File | What it is | Where it comes from |
| --- | --- | --- |
| `Sources/UsageBar/HouseDesign.swift` | Design tokens (colours, type, spacing) | Generated by the House design system from its `tokens.json` |
| `Sources/UsageBar/HouseUI.swift` | Slate component kit: panel glass, rows, cards, status dot, toggles | Shared House kit, first written for Cotype |
| `Sources/UsageBar/AppActivation.swift` | When a menu-bar app takes the foreground | Shared with [Quick Launch](https://github.com/tristan-mcinnis/quick-launch) |
| `Sources/UsageBar/MenuBarPanel.swift`, `RenderProof.swift`, `SettingsMenu.swift` | Panel controller, render proof, settings shell | Shared House menu-bar plumbing |
| `Resources/AppIcon.icns` | App icon (a gauge drawn with plain shapes) | Rendered by the House design system's icon renderer |

## Apple system frameworks and symbols

Usage links only Apple's system frameworks (Foundation, AppKit, SwiftUI,
Combine, Network, ServiceManagement). The menu-bar glyph is the SF Symbol `gauge.with.needle`,
drawn by macOS at run time through `NSImage(systemSymbolName:)`; no symbol
artwork is bundled. SF Symbols are provided by Apple under the
[Xcode and Apple SDKs agreement](https://www.apple.com/legal/sla/) and are
used here only as an interface glyph, not in the app icon.

## Provider endpoints

Usage reads usage and balance numbers from Anthropic (Claude Code), OpenAI
(Codex), Google (Antigravity, through its own `agy` CLI), DeepSeek, Moonshot,
and Soniox. No code from those providers is included. Their names are used
only to label the rows. See the README's Privacy section for which endpoints
are official and which are not.
